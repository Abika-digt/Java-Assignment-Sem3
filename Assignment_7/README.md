
# Assignment 7 – Counting Steps and Complexity

## Aim
To count the number of steps a program takes and understand its time complexity.

---

## Question 1 – Count Steps Using One Loop

**Aim:** To count the number of times a single loop executes.

**Source Code:** `Question1/Main.java`

**Output:**
```text
Steps: 10
```

**Time Complexity:** O(n) – Linear Time

**Concepts Used:**
- for loop
- Counter variable
- Time complexity

**Result:** Successfully counted 10 loop executions.

---

## Question 2 – Count Steps Using Nested Loops

**Aim:** To count the total executions of the inner loop using nested loops.

**Source Code:** `Question2/Main.java`

**Output:**
```text
Steps: 100
```

**Time Complexity:** O(n²) – Quadratic Time

**Concepts Used:**
- Nested loops
- Counter variable
- Time complexity

**Result:** Successfully counted 100 executions of the inner loop body.

---

## Question 3 – Count Halving Steps

**Aim:** To repeatedly divide a number by 2 until it becomes 1 and count the divisions.

**Source Code:** `Question3/Main.java`

**Output:**
```text
Halving steps: 10
```

**Time Complexity:** O(log n) – Logarithmic Time

**Concepts Used:**
- while loop
- Integer division
- Counter variable
- Logarithmic time complexity

**Result:** Successfully counted 10 halving operations for the number 1024.

---

## Overall Conclusion

All three programs were successfully implemented in Java to understand how to count program execution steps. The assignment demonstrated linear, quadratic, and logarithmic time complexities.
